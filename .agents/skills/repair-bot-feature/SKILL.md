name: repair-bot-feature
description: Изменять пользовательские сценарии Telegram-бота заявок на ремонт, не нарушая роли, FSM и слои handlers/CRUD.
---

Используйте этот навык при изменении регистрации, профиля, заявок, статусов,
клавиатур, обработчиков Aiogram или связанного CRUD.

1. Прочитайте `specs/features/repair-requests.md`, `AGENTS.md` и затронутые обработчики.
2. Сохраняйте границы слоёв: Telegram-ввод и авторизация — в `handlers/`, операции с данными — в `crud/`.
3. Права определяйте по числовому Telegram ID и allowlist из окружения; не доверяйте username или callback-данным.
4. Для нового или изменённого поведения добавьте тест с изолированной фикстурой `db_session`, когда это применимо.
5. Выполните `python -m ruff check .` и `python -m pytest -q`; сообщите результаты.
